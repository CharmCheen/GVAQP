# Independent project reconstruction

This reconstructs the project from the underlying artifacts, deliberately not
from `PROJECT_STATE_OF_TRUTH.md` or historical prose. The vocabulary below
follows the mandated six-level claim vocabulary.

## 1. What the repository actually tests

The repository does **not** faithfully test the original motivation: "a query
processor uses cheap acquisition, expensive semantic verification, feedback,
and limited resources to progressively recover high-quality temporal
EventRelation answers despite imperfect proxy observations."

What the finalized evidence actually tests is a reduced, cached,
model-relative replay problem:

- **Candidate universe is precomputed.** 1475 units, exactly one candidate per
  10-second unit (`CANDIDATE_EXISTENCE_AUDIT.md`: 1475/1475 precomputed, 0
  generated by SCAN). Exposure recall is structurally 1.0.
- **SCAN is information release, not sensing.** `src/rc_sem/sequential.py`
  reveals precomputed proxy rows from a stored cell; it reads no raw video and
  runs no cheap model. Costs are abstract (0.1 vs 1.0), not measured.
- **VERIFY reveals a cached model-relative label**, not an authoritative
  semantic observation of raw video.
- **Ground truth is a Qwen3-VL-32B model-relative label table**, and the event
  reference is K3-grouped from those same labels (`REFERENCE_CIRCULARITY_AUDIT.md`).
- **Budget is oracle-call count, not physical wall-clock time.**

Consequently the demonstrated bottleneck is **ranking**, not the original
acquisition/feedback loop. The tested problem is "budgeted reconstruction of a
K3-defined model-relative event relation from precomputed candidates under an
imperfect proxy ranker."

## 3. What is established, what is not

**Established (bounded, model-relative):**
- Proxy ranking quality is weak and video-dependent (AUPRC 0.2584–0.3146).
- Ranking degradation produces a material low-budget EventF1 gap (0.0951);
  synthetic exposure degradation produces 0.0 by construction.
- Gap-constrained C1 materialization dominates naive merge on 54/54 controlled
  pairs (median ΔF1 +0.1457), robust across 3 videos and 3 selectors.
- Nearly all of that gain is the 10-second gap rule (median +0.1377); duration
  cap, negative barrier, and K3 extras contribute ≈ 0.
- Nested-policy quality is near-monotone in oracle-call budget (0.48% violations).
- On the cached 108-state audit, learned action selection is worse than fixed
  always-VERIFY (regret 0.009693 vs 0.000885).

**Not established:**
- Whether equal-yield evidence geometry improves independently human-defined
  event recovery (H1). Waiting on human reference; shadow is LOW.
- Whether faithful endogenous costly/incomplete SCAN creates non-rare, material,
  policy-visible action regret (H2). Never faithfully tested.

## 4. The two live falsifiable questions

1. **H1 (geometry/human):** at equal verified-positive count, does broader
   policy-visible temporal evidence geometry recover more independent human
   events? Gate = P1 human reference.
2. **H2 (endogenous SCAN regret):** in a real online cheap-sensing process, do
   naturally visited states contain non-rare, material, predictable
   SCAN-vs-VERIFY regret? Gate = future P4 faithful substrate.

Everything else is a bounded system finding, a weakened hypothesis, or a
closed branch. This matches the project's own state but was reached
independently from the artifacts.

## 5. Independent corrections / sharpening of the project's own account

- The project correctly uses NOT_ESTABLISHED for B/C/K. This audit agrees, and
  additionally stresses that the original theory has been **masked, not
  falsified**: the load-bearing assumption (natural exposure false negatives)
  is structurally impossible to observe on the current substrate.
- The "positive" empirical story (materialization gain, geometry R²=0.795) is
  entirely **reference-relative**. The reference is K3-defined from the same
  model whose labels drive the method. This is the single largest
  construct-validity weakness and it is only partially mitigated by the
  circularity audit.
- The controller NO-GO is correctly bounded to the substrate, but this also
  means the original "does adaptive allocation help?" question is **unanswered**
  rather than answered in the negative.
