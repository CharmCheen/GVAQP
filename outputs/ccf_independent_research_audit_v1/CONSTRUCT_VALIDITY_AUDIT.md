# Construct validity audit

Each line maps a construct the research claims to study onto what the
instrument actually measures, and flags validity threats.

## 1. Precomputed candidate universe vs endogenous candidate generation

- Claimed construct: SCAN reads raw video and endogenously generates fallible
  candidate evidence.
- Measured: candidate universe is fully precomputed (1475/1475); SCAN releases
  stored rows; 0 candidates generated by SCAN (CANDIDATE_EXISTENCE_AUDIT.md).
- Validity: LOW for the original theory. The only failure mode preserved is
  ranking, not acquisition. This is the single most consequential
  construct-mismatch in the repository.

## 2. Ranking error vs exposure error

- Ranking error is real and measured (AUPRC 0.258-0.315). Exposure error is
  structurally zero (one candidate per unit). E1-E3 regimes inject synthetic
  exposure deletion, correctly labeled SYNTHETIC_DIAGNOSTIC_ONLY and not a
  model of natural detector misses.
- Validity: the two error classes are cleanly separated (good), but the
  theoretically central exposure error is never observed naturally.

## 3. True SCAN semantics

- sequential.py SCAN = reveal precomputed proxy rows from a stored cell;
  constant abstract cost 0.1; no raw-video read; no cheap-model execution; no
  candidate identity creation. Semantic decomposition: new raw observation
  0/108, new candidate identity 0/108, release precomputed evidence 108/108.
- Validity: EMULATED_INFORMATION_RELEASE, partial only.

## 4. VERIFY semantics

- VERIFY reveals a cached model-relative label for an already-scanned unit;
  cost 1.0. It is not an authoritative semantic observation of raw video and
  cannot correct proxy errors beyond returning the precomputed label.
- Validity: partial. Expensive semantic verification is emulated by a lookup.

## 5. Partial observability

- The environment is internally partially observable (unscanned proxy values
  hidden, VERIFY illegal until scanned), and sequential.py keeps evaluator-only
  fields out of public state. This part is faithful.
- Validity: HIGH for the emulated information-release loop.

## 6. Behavior-policy state sampling

- The 108-state branch table comes from four prior behavior policies,
  deduplicated and capped at 12 per domain-budget. It is not a probability
  sample from a natural online sensing process.
- Validity: NOT_IDENTIFIABLE whether rarity is behavior-policy artifact or
  natural. Any 98/108 indifferent prevalence claim is not generalizable.

## 7. Action-regret prevalence

- 5 beneficial / 5 harmful / 98 indifferent at delta 0.005 describes this table
  only. No natural prevalence estimate exists. Two precision-boundary crossings
  contribute 96.6% of positive deviation value.
- Validity: LOW for any claim about how often adaptive allocation would help in
  a real system.

## 8. Q / reward discontinuities

- Frozen Q = 0.5 terminal recall + 0.5 anytime AUC - 1[nonempty precision<0.8].
  The discontinuous penalty dominates positive gain magnitude; removing it
  shifts classes from 5/5/98 to 5/4/99 but rank correlation stays 0.899.
- Validity: mixed. Positive headroom is discontinuity-dominated; the smooth
  component still has structure, but headline beneficial states are largely
  penalty-avoidance, not genuine event-utility.

## 9. Event-reference construction and K3/C1 circularity

- Reference events are K3-grouped from the same Qwen3-VL-32B unit labels used
  by the method. REFERENCE_CIRCULARITY_AUDIT.md flags this. K3 and C1 share the
  same 10-second gap family, so materialization gain can partly be an artifact
  of matching the evaluator's own grouping rule.
- Validity: fatal for unconditional K3 superiority; acceptable only as a
  conditional mechanism study.

## 10. Human-reference status

- Frozen human label log has 0 rows. All P1 results are automated/model-relative
  or VLM-shadow. No PASS/FAIL exists.
- Validity: no independent-human conclusion is possible yet.

## 11. VLM-direct shadow result

- Same Qwen3-VL-8B checkpoint in two sessions; A has 176 events, B 73; global
  matched-event fraction 0.313. Only 2/6 clusters positive. Geometry MAE gain
  0.000665.
- Validity: LOW as an independent reference (same checkpoint, low agreement).
  Correctly treated as low success potential, not human truth.

## 12. Proxy dependence

- Proxy A (YOLOv8n) carries most positive signal; Proxy B (optical flow) is
  weakly correlated (rank Spearman -0.029 to 0.176) and weak for labels.
  StaticProxyRank advantage is proxy-specific.
- Validity: proxy-sensitivity is high; robust-policy claims are not yet
  two-proxy robust.

## 13. Geometry hypothesis

- Model-relative LOVO R2: 0.006 (yield) to 0.795 (+public geometry) to 0.980
  (reference-aware). But it is K3-reference-relative and does not transfer to
  the shadow. number_of_temporal_regions_touched is close to C1's own 10-second
  cluster rule.
- Validity: real in the model-relative K3 world but likely an artifact of the
  C1-shaped reference; not independently supported.

## 14. Controller NO-GO result

- Correctly bounded: it falsifies learned deviation on the current reduced
  substrate, not adaptive allocation in general. The honest statement is no
  evidence of learnable headroom on this substrate, not adaptation impossible.

## 15. Model-relative P2 conflict (ordering violation)

- The P2 novelty-killer diagnostic ran before human P1 was resolved. This is a
  procedural ordering violation; the project correctly marks P2 INCONCLUSIVE /
  NON-AUTHORIZING and prohibits P3. Content is valid as a diagnostic but cannot
  substitute for the gated sequence.

## 16. P1-P2-P3-P4-P5 ordering justification

- The ordering is scientifically justified: establish event-aware benefit on an
  independent reference (P1) before surviving a generic killer (P2) before
  proposing an event-aware policy (P3) before testing faithful endogenous SCAN
  regret (P4) before building a controller (P5). Historical execution violated
  it (P2 early); the state machine now enforces it. No downstream stage is
  authorized by code existence alone.

## Bottom line

The repository has excellent process validity (preregistration, hashes,
controlled pairs, leave-one-out, bootstraps) but weak construct validity at the
two decisive points: (a) candidate acquisition is precomputed rather than
endogenous, and (b) the event reference is K3/model-relative rather than
independent. Both sit exactly at the load-bearing claims of the original theory.
