## LFS / git-lfs situation

- The repo has a `.gitattributes` referencing LFS patterns (see `AGENTS.md` "大型产物警告").
- `git-lfs` is **not** on `$PATH` in this environment.
- LFS-routed files (if any) are stored as LFS pointer stubs that point to an LFS object store that the LFS smudge filter would normally resolve. In this environment, the pointer is unresolved; `git status` still sees the LFS-tracked files but `git checkout` would not bring them back.
- The four > 100 MB CSVs above are **not** LFS-routed. They are stored as plain blobs in git history.
