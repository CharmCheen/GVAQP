# probe_set_v1 Annotation Package

This package is a static index over existing probe media.

Files:

- `index.html`: browser index for review.
- `annotation_manifest.csv`: media path manifest.

Restrictions:

- Do not use probe labels for tuning, threshold selection, selector choice, repair decisions, or candidate generation.
- Annotation fields remain in `../probe_set_review_sheet.csv`.
- No VLM, YOLO, GPU, or API inference was run to build this package.
