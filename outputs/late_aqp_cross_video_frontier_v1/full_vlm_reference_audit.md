## Schema

- Each atomic unit is a 10 s center-10 anchor.
- `label` is `positive` / `negative` per anchor.
- `event_cluster_id` groups adjacent positive anchors into events.
- `event_start_absolute` / `event_end_absolute` give event time within the full video.

## Coverage

- Video duration: 3462.930 s
- Number of 10 s anchors: 347
- Reference events after cluster merging: 27
- Long intervals (>=1 s): 6
- Point anchors (<1 s): 21

## Audit conclusions

- Full-VLM reference is a development-time artifact; only used for oracle adapter and final evaluator.
- Every 10 s anchor has a binary label and a `score_yolo_count` prior.
- Event precision/recall can be computed via overlap between selected intervals and reference events.
- Duration precision/recall can be computed via overlap duration.
- B_90/90 can be computed over the evaluated budget grid.
