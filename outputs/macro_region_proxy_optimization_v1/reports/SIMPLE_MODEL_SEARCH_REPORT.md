# Simple Model Search Report

The bounded search evaluated 45 configurations across M0 heuristic, M1 logistic, M2 Poisson, and M4 constrained shallow forest. Every prediction used the other complete video for fitting. The selected combination model was `CFG_16` (M1_LOGISTIC, S5_STABLE), with macro Recall@20 0.226 and minimum-video Recall@20 0.223.

It did not beat the univariate heuristic (0.268 macro). Complexity therefore earned no place. The Stage-A design candidate remains the univariate heuristic, but only as a failed exploratory candidate—not a selected proxy.
