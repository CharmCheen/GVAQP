# H1B error-target canonicalization A2

This result-blind amendment resolves the remaining implementation freedom in
the A1 error model. It binds to the A1 freeze manifest and changes no scientific
claim, configuration, or Gate threshold.

At each simulated planner state, order candidates lexicographically by
`(hypothesis_id, witness_id)` and actions by frozen `ActionR2.identifier`.
Canonical target identities and draw indexes are:

| Mechanism | target identity | draw index |
| --- | --- | --- |
| SCAN candidate yield | `SCAN|region_id|hypothesis_id|witness_id` for each generated candidate | ordered candidate rank within that scan |
| CONFIRM positivity | `CONFIRM|hypothesis_id|witness_id` | candidate rank in the pre-action frontier |
| novelty/duplicate | `NOVELTY|hypothesis_id|witness_id` | candidate rank in the pre-action frontier |
| grouping transition | `GROUP|hypothesis_id|min(witness_i,witness_j)|max(witness_i,witness_j)` for every same-hypothesis unordered pair | pair rank after lexical target sort |
| action duration | `DURATION|ActionR2.identifier` | action rank in the pre-action legal-action order |
| materialization | `MATERIALIZE|hypothesis_id|witness_id` | candidate rank in the pre-action frontier |

Every error draw uses the UTF-8 SHA-256 key
`H1B_ERROR|seed|decision_index|mechanism|form|trajectory_index|target_identity|draw_index`.
The first digest bit supplies the A1 Rademacher sign. The same full key must be
used for common-random-number comparisons, so corresponding action-pair draws
are identical whenever their canonical target exists in both simulations.

State-dependent signs use the target candidate's frozen `score_bin`: `+1` iff
it equals the maximum score bin in the current pre-action frontier, otherwise
`-1`. A CONFIRM/novelty/materialization target absent from the frontier is
invalid and blocks the trace. A duration target uses the linked CONFIRM
candidate when present; SCAN, STOP, and a duration action without linked
candidate use `-1`. A generated SCAN candidate uses its generated score bin
against the maximum score bin among candidates generated by that same scan.
For an empty frontier, no candidate/pair/confirm/novelty/materialization draw
exists; SCAN/STOP duration uses `-1`. Empty target sets are serialized as empty
ordered lists, never as implicit random draws.
