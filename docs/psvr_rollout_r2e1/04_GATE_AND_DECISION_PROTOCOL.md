# Gate and decision

The E1 emitter reads only independent verifier products. It requires complete
M1/B1/B4 pairing, then evaluates the inherited paired macro/median comparisons
without changing a threshold or method identity. It may emit only
`ACCEPT_IDEAL_MECHANISM`, `REJECT`, or `BLOCKED_EXECUTION_INTEGRITY`, mapped to
the already-frozen H-ROLLOUT1A-R2 branches. It must not inspect coordinator
derived tables.
