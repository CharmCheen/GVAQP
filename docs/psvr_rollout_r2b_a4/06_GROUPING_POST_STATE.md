# A4 grouping post-state

For each newly emitted witness, `CORRECT` attaches it to the first active
same-latent-event hypothesis or creates a new hypothesis. `UNDER_MERGE` always
creates a new hypothesis. `OVER_MERGE` attaches it to the first active
different-latent-event hypothesis, or deterministically falls back to
`CORRECT` when none exists. Hypotheses sort by `(created_at, hypothesis_id)`.
New IDs are SHA-256 of the A4 stable-ID tuple specified in the amendment.
Only the sampled planner root world can see latent event identity; policy state
exposes only IDs, membership, and flags.

A4 retains every A2 grouping variable instance: for each same-source-
`hypothesis_id` unordered pair among all candidates generated by a SCAN it draws the canonical
`GROUP|hypothesis_id|min(witness_i,witness_j)|max(witness_i,witness_j)` target
at lexical pair rank. A4 then supplies the missing post-state mapping: a
witness uses the first non-`CORRECT` outcome among its incident pair draws in
lexical pair-rank order, or `CORRECT` when it has no incident pair. This adds
no target, magnitude, form, or grid cell, and makes pair-level A2 signs/draws
deterministically govern the A4 per-witness transition. Candidate yield
controls which witnesses are emitted, not which A2 pair target identities or
lexical ranks exist; outcomes incident to a non-emitted witness remain a
deterministic unused draw.

CONFIRM resolves and suppresses only its selected model hypothesis; other
model hypotheses remain active. This is the canonical under-merge duplicate
path, while resolving an over-merged hypothesis suppresses every witness it
contains.
