# H1B A4 authority and scope

`H1B_A4_GENERATIVE_TRANSITION_SEMANTICS` is a result-blind scientific
clarification authorized after IC1 proved that A1/A2 did not uniquely define a
generative model-error experiment. It supplements BASE → A1 → A2 → A3 and
changes no grid, seed, method, metric, Gate, D1/D2/D3, or evaluator kernel.

It freezes only the approximate planner's baseline transition kernels,
operator order, keyed realization, coupling, JOINT composition, grouping
post-state, action schedule, and canonical transition serialization. The
evaluator remains the unperturbed frozen R2 environment.
