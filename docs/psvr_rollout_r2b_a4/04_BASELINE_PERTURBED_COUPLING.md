# A4 baseline–perturbed coupling

For a semantic variable instance, baseline and perturbed model outcomes use
the same A4 key and the same `U`. The baseline outcome is the inverse-CDF
outcome under `P0`; the perturbed outcome is the inverse-CDF outcome under the
A2-transformed distribution. Candidate-action branches share keys for
semantically corresponding variables. Branch-only entities derive a stable
child entity ID from their branch lineage.
