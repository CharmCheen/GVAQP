# A4 mathematical audit

A4 turns every semantic random variable into one inverse-CDF evaluation over a
named distribution and one stable key. Thus identical state, A2 configuration,
root world, action lineage, and trajectory produce byte-identical transition
records. The previous IC1 counterexample is resolved because A4 selects the
first-eight-byte keyed uniform rather than leaving the hash-to-uniform map
unspecified.
