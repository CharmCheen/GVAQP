# D3/D4 visible-history kernel amendment

`D3D4_VISIBLE_HISTORY_KERNEL_R2` was made before policy results. It preserves
D1 utility, D2-L pi0, D2-T bounds, workload axes/regimes, baseline identities
and acceptance logic. It adds finite tick/binned representation, history,
interventional likelihood, exact posterior, conditional full-horizon rollout,
RNG isolation, fixed draw derivation and seed visibility semantics.
