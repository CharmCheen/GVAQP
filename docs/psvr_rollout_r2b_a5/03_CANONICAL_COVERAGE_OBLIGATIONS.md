# Canonical coverage obligations

The frozen core specifies four error forms and magnitudes `0`, `.05`, `.10`,
and `.20`, alongside the target, budget, planning-cost, and method families.
The original 13 rows contain only systematic optimism/pessimism and magnitudes
`0`, `.05`, `.10`.  Thus the registry does not satisfy the document's claimed
full form/magnitude coverage.

The six runtime rows would cover omitted forms/magnitudes, but post-result
runtime code cannot retroactively supply pre-result scientific authorization.
This is the conflict which prevents the A5 freeze.
