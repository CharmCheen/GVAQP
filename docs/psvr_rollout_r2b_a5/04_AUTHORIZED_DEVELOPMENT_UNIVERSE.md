# Authorized development universe

For preservation and reproducibility, A5 materializes the original 390
identities with an explicit complete-universe hash.  It labels the set
`PROVISIONAL_ORIGINAL_ONLY_NOT_FROZEN`: it is the historical registry, not an
authorized replacement for the full frozen grid.

The 570 runtime set is retained only as `UNBOUND_RUNTIME_EFFECTIVE_UNIVERSE`.
No runtime-added row is diagnostic-only, because its stated purpose is to fill
scientific error axes, not a non-scientific boundary fixture.
