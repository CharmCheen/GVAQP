# Closed-route ledger

This ledger treats a route as closed only at the scope established by its
artifact. A theoretical possibility is not promoted over a negative frozen
experiment.

| Route | Decisive observed evidence | Closed claim | What would constitute a genuinely new premise |
|---|---|---|---|
| BCM counterfactual event-hypothesis planning | BCM AUC 0.294270; all first 100 actions were core discovery | The implemented BCM state, candidate builder and surrogate do not provide a viable planner | A different physical operator or query object, not another surrogate weight or hypothesis repair |
| H1 saturation/exploration/counterfactual planning | H1 AUC 0.314990; exploration effect negative; counterfactual effect about 0.001 AUC | Do not rerun P2/P3 or rename the same adaptive planner | An operator returning different information than unit presence |
| Public event-cell ownership repair | R1 P1-P0 AUC -0.003501139; negative in 15/15 cells | Event-cell reownership does not rescue saturation | New information or operator semantics, not a new owner graph |
| K3/BCEM partition heuristics | Exact legal-partition gap only +0.000870165 AUC; public BCEM -0.007520160 versus K3-safe | Geometry/barrier-only materialization tuning on this reference is closed | Planner-public same-event evidence or a physical operator returning event identity/boundaries |
| Additional CLIP/X-CLIP ranking | CLIP improves AUC to 0.538949 but requires 311 total Gate-B calls; X-CLIP is worse | No more prompt/model/fusion tuning on the strict video | A new semantic operator that changes more than ordering |
| Unit-ranking DARE | Best public total 311/347; ideal rank is feasible but public rankings are not | Ranking plus exact residual audit does not meet the 70% cost target | A set-valued operator that returns several event objects per invocation |

| Risk-limiting interval pruning | 0/56,448 robust cells; minimum all-placement quality cost 550/347 | Auditing provisional negatives cannot meet the frozen unit-audit cost target | Lower-cost audit primitive measured independently, or a non-pruning event-producing operator |
| ECP/event-operator bandit in the worktree | Design overlaps the failed exploration/counterfactual family and has no sealed held-out result | It cannot be relabeled as the new sprint algorithm | A different optimization problem with a falsifiable operator/cost mechanism |
| More embedding models or tuned prompts | Explicitly prohibited and already diagnosed as weak public separability | No model zoo or strict-reference prompt tuning | None within this sprint |

The open branch retained for candidate generation is direct, set-valued
`EVENT_ENUMERATE(interval)` plus cost-based variable-resolution query planning.
It is not yet supported: its physical accuracy and cost are decision-critical
unknowns and must be falsified before any positive claim.
