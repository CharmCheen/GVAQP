# BSEC AQP development gate v1

Start with `REPORT.md` for the scientific conclusion and caveats. `METHOD.md` specifies the current PSTR-5:4 candidate; `RESEARCH_STATE.md` preserves accepted/rejected hypotheses and the next decision; `REPRODUCE.md` contains replay commands.

The package preserves three failed branches (BSEC, QTPC, PNIR), the narrow frozen DASR gate, a 1,000-seed post-hoc ARC audit, and the exploratory PSTR branch. The current status is a frozen candidate awaiting an independently sourced prospective confirmation—not a broad claim that PSTR or DASR universally beats native ARC. The terminal future-test contract is v5; v4 is retained as a superseded historical freeze.

Machine-readable terminal checks are in `outputs/VERIFICATION.json`; frozen protocols are under `config/`; independent review is under `review/`.
