## 4. ARC Input Format Discovery

### 4.1 CDF CSV Format

ARC's `generate_oracle_proxy()` (in `arc_source/arc/tools.py`) expects:

```python
predicates = df['predicates'].values        # raw numeric values
o_1 = P(predicates, op, constant)            # oracle_label = (x > constant)
p_0 = df[str(constant)].values               # proxy CDF = P(proxy ≤ constant)
p_1 = 1 - p_0                                # P(proxy > constant)
proxy = np.column_stack((p_0, p_1))          # [P(0), P(1)]
proxy_score = np.argmax(proxy, axis=1)       # 0 or 1
```

**Key insight**: The `predicates` column must contain raw values (not binary labels), because ARC applies `x > constant` to derive oracle labels.

### 4.2 ARC Constant ≠ K

ARC uses strict `>` operator. To get `(vehicle_count >= K)`:
- Store `constant = K - 1` in the CDF column name
- ARC computes `(count > K-1)` = `(count >= K)` ✓

### 4.3 ARC Runtime Constant = 0

**Critical discovery**: In `algorithm_handler.py` line 53-55, ARC is always called with `constant=0`:

```python
def _arc(function, proxy, oracle, proxy_score, oracle_score, B, op, tau, ...):
    Algres = function(proxy, oracle, proxy_score, oracle_score,
                      B, '>', 0, tau, ...)  # constant=0!
```

The `constant` parameter in the config is only used for `generate_oracle_proxy` to select the CDF column. The actual ARC algorithm uses `constant=0` to find clips where `score > 0`.

### Proxy CDF Computation

The proxy CDF is computed using a sliding window:

```
proxy_positive[i] = 1 if proxy_vehicle_count[i] >= K else 0
P(proxy > K)[i] = sliding_window_mean(proxy_positive, window=30)
CDF[i] = P(proxy ≤ K) = 1 - P(proxy > K)
CDF[i] = clip(CDF, 0.001, 0.999)
```

Statistics (K=13): mean=0.9523, std=0.1015, min=0.4516, max=0.9990

## 7. Adapter Script

Location: `scripts/build_arc_input_from_counts.py`

Usage:
```bash
python scripts/build_arc_input_from_counts.py \
    --input outputs/garc_meeting_pack/real_video_csv_pipeline/realcar_5k.csv \
    --dataset realcar_5k \
    --K 13 \
    --tau 30 60 120 \
    --cdf-window 30 \
    --output-dir data_moving_arc
```

The script:
1. Loads per-frame CSV
2. Computes raw oracle counts (for ARC's `predicates` column)
3. Computes proxy CDF = P(proxy ≤ K-1) via sliding window
4. Generates temporal cluster labels
5. Finds ground-truth clips for each tau
6. Writes ARC-compatible CDF CSV, cluster CSV, and metadata

## 8. Limitations & Findings

### 8.1 Proxy Signal Weakness

The proxy model (YOLOv8n) has significantly fewer detections than the oracle (YOLOv8x):
- Mean proxy count: 6.17 vs oracle count: 7.82
- At K=13: proxy positive rate 4.70% vs oracle 14.30%

This means ARC's proxy CDF is almost always > 0.5, so `proxy_score = argmax(proxy)` is almost always 0. ARC relies on proxy_score to find candidate clips; with such low proxy positive rate, ARC has limited signal to work with.

### 8.2 ARC Confidence Issue

ARC's confidence stays at 0.0 throughout the run. This is because:
1. `calculate_confidence()` computes confidence based on proxy probabilities
2. With very low proxy positive rates, the confidence is near zero
3. ARC terminates early without achieving the target confidence (0.9)

This is a data characteristic, not an adapter bug. The moving-camera data has inherently weak proxy signals for high-count thresholds.

### 8.3 No ARC Algorithm Modification

The adapter does NOT modify any ARC code. All changes are in:
- `scripts/build_arc_input_from_counts.py` (new file)
- `data_moving_arc/` (new output directory)

## 9. Recommendations for Full Experiment

1. **Lower K**: Use K=10 or K=11 for stronger proxy signal
2. **Multiple datasets**: Run adapter on `video_supg.csv` (test.mov) for comparison
3. **ARC integration**: To run ARC experiments, either:
   - Copy CDF CSV to `arc_source/data/CDF/realcar_5k.csv`
   - Or modify `experiment_config.py` to add `realcar_5k` to DATA_DIRS
4. **Constant parameter**: Remember to pass `constant=0` when calling `arc()`, not the data constant
